# Harbor Framework Website

A beautiful, modern website showcasing the advantages of the Harbor Framework for LLM Agent Evaluation.

## Features

- 🎨 Modern, responsive design
- ⚡ Smooth animations and interactions
- 📱 Mobile-friendly layout
- 🚀 Fast loading with no build step required
- 🎯 Clear presentation of Harbor's advantages

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)

### Installation

No installation needed! The website uses only npm scripts to serve static files.

### Running the Website

Start the development server:

```bash
npm start
```

Or use the dev script:

```bash
npm run dev
```

The website will be available at `http://localhost:3000`

### Building

This is a static website, so no build step is required. Simply deploy the files:

- `index.html`
- `styles.css`
- `script.js`

## Project Structure

```
harbor-website/
├── index.html      # Main HTML file
├── styles.css      # All styles and animations
├── script.js       # Interactive JavaScript
├── package.json    # npm configuration
└── README.md       # This file
```

## Customization

You can easily customize the website by:

1. **Colors**: Edit CSS variables in `styles.css` (root section)
2. **Content**: Modify the HTML in `index.html`
3. **Animations**: Adjust JavaScript in `script.js`

## Deployment

You can deploy this website to any static hosting service:

- Netlify
- Vercel
- GitHub Pages
- AWS S3
- Any web server

Simply upload the `index.html`, `styles.css`, and `script.js` files.
